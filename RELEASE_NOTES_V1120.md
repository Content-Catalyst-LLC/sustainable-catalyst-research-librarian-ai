# Research Librarian AI v11.2.0 — Statistical Analysis Planning Intelligence

v11.2.0 introduces durable prospective statistical-analysis planning above the v11.1 Study Protocol & Preregistration Engine.

The release adds study-protocol and preregistration lineage, estimand definitions, model specifications, assumption checks, power/sample-size planning records, multiplicity planning, missing-data strategies, sensitivity analyses, reporting commitments, human approval decisions, analysis matrices, structural readiness, non-executing runtime handoffs, Platform Core candidates, immutable snapshots, authenticated APIs, durable snapshot jobs, unified-environment bindings, and migration 027.

The release deliberately does not replace the existing v8.11 Statistical Research integration. v11.2 plans statistical work prospectively; v8.11 remains the specialist-runtime/Platform Core bridge for governed statistical execution artifacts. No automatic method/model selection, power calculation, significance inference, causal inference, execution, result interpretation, or truth promotion is performed.
