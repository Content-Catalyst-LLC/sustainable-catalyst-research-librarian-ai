# Research Librarian AI v11.0.0 — Research Program Intelligence

v11.0.0 elevates the v10.x research-planning sequence into persistent program-level coordination. It can organize multiple linked research activities without turning the Librarian into a scientific decision-maker or execution engine.

## Added
- Durable research programs with mission, objectives, program identity, Core project lineage, and linked v10.9 computational plans.
- Workstream registry with human-declared leads, states, dependencies, expected outputs, and computational-plan bindings.
- Governed component-binding registry for v10.x plans, scholarly objects, AI research objects, knowledge graph nodes, exchange packets, and Core references.
- Program milestones with dependencies, workstream/binding requirements, acceptance criteria, and explicit human milestone decisions.
- Deliverable registry with milestone/workstream/binding lineage and external artifact references.
- Program-level constraints and blocking conditions.
- Program graph, descriptive portfolio summary, and structural readiness.
- Non-writing program/workstream handoff packets.
- Platform Core `research-program` candidates without automatic promotion.
- Immutable program snapshots and durable `research-program-intelligence-snapshot` jobs.
- Unified scholarly/AI research environment binding as `research-program`.
- Postgres migration `025_research_program_intelligence.sql`.

## Governance
Research Program Intelligence coordinates work but does not certify scientific validity. Program readiness is structural, component authority remains with source systems, specialist runtimes retain execution, and Platform Core remains governed research-object authority. Research prioritization, resource allocation, milestone completion, scientific judgments, execution, and truth promotion are never automatic.
