# Research Librarian AI v11.0.0 — Research Program Intelligence

v11.0.0 introduces a durable program-level coordination and lineage layer above the v10.x research-planning sequence. A research program can contain multiple workstreams, component bindings, computational plans, milestones, deliverables, constraints, and human review decisions while preserving authority in the systems that own each research object.

## Capabilities

- durable research-program records and event lineage
- workstream registry with declared dependencies
- binding registry for v10.x research objects and later scholarly/AI artifacts
- computational-plan lineage inherited from v10.9
- milestone dependency graph and explicit human milestone decisions
- deliverable registry and artifact references
- program constraints and blockers
- descriptive program portfolio summary
- structural program readiness
- non-writing workstream handoff packets
- Platform Core `research-program` candidates without promotion
- immutable research-program snapshots
- durable `research-program-intelligence-snapshot` jobs
- unified v10/v11 environment binding as `research-program`

## Governance

Research Program Intelligence coordinates research; it does not determine scientific validity. Component authority remains with source systems, specialist runtimes retain execution, Platform Core remains the governed research-object authority, and humans approve program state and milestone decisions. There is no automatic research prioritization, resource allocation, milestone completion, scientific judgment, execution, or truth promotion.
