# Research Librarian AI v10.3.0 — Evidence Search Strategy Engine

v10.3.0 turns the question/hypothesis and methodology layers into reproducible evidence-search protocols.

## Highlights
- Question- and methodology-linked search strategies.
- Deterministic concepts/synonyms and Boolean query construction.
- Explicit Knowledge Library/federated/external source targets.
- Inclusion/exclusion protocol rules and date/language/source-type constraints.
- Evidence-requirement-to-query coverage mapping.
- External execution receipts for auditable search history.
- Human approval before search handoff.
- Knowledge Library/federated discovery execution packets without automatic search/import.
- Platform Core `evidence-search-protocol` candidate without automatic promotion.
- Immutable snapshots, durable async snapshot job, migration 018, and unified-environment binding.

## Governance boundary
Search planning is not source acceptance. Search receipts are not evidence validation. Coverage is protocol mapping, not evidence sufficiency. Knowledge Library retains ingestion/retrieval authority, Platform Core retains governed evidence-object authority, and human review remains required.
